# Link-in-Bio Static Website

A responsive, mobile-first "Link-in-Bio" landing page built with semantic HTML5 and modern CSS3, showcasing Java backend and DevOps projects, hosted freely via GitHub Pages.

## Project Structure
```text
link-in-bio/
├── app/
│   ├── index.html     # Main markup structure and professional links
│   └── style.css      # Modern responsive styling (dark mode, glassmorphism)
├── multi-media/
│   └── 9562.jpg       # Profile image asset
└── README.md          # Project documentation
```

## Features
- **Mobile-First Design:** Fully responsive layout optimized for mobile screens.
- **Modern UI:** Clean dark-mode aesthetic with subtle gradients, smooth hover transitions, and accessible typography.
- **Fast Performance:** Pure static HTML/CSS with zero external heavy frameworks or JavaScript dependencies.

## Deployment
Hosted live on GitHub Pages.
